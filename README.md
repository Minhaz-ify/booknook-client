# BookNook – A Small Online Library

**Live site:** https://booknook-client-727g.vercel.app/

Add a book, borrow a book, return a book.

## Features
- Email/password and Google login with BetterAuth and the MongoDB adapter
- Browse all books and see the 6 newest arrivals on the home page
- Add, edit and delete your own books with image upload and confirm modals
- Borrow a book with a return date, see your borrows and return them anytime
- Copy tracking: no double borrow, and "Not Available" when stock runs out
- Dark / light theme and a fully responsive layout

## Run locally
```
npm install
cp .env.example .env.local
npm run dev
```
